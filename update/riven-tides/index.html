Riven Tides

Released Apr 28, 2026Version 1.26.0

A coastal map with a new boss-style ARC and a durability rework.

Key changes

  • New map Riven Tides with the exclusive Beachcombing condition for finding buried treasure.
  • New ARC Turbine floating enemy; new items include the Powered Descender, Crash Mat, White Flag, Dockmaster's Detector and Tactical Mk. 3 (Smoke).
  • Trials Season 4, the Last Resort event (ship model rewards) and the Avian Alarm project.
  • Weapon durability rework: upgrades repair 25%, spawned weapons average 30 durability instead of 50, knocked-out loss halved.
  • Bettina damage up with a lower fire rate; Photoelectric Cloak power use raised; Comets removed from standard Dam Battlegrounds.
