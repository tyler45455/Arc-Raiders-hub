Forgotten Relics

Released Jun 16, 2026Version 1.33.0

A relic-hunting event and a long-running community project.

Key changes

  • Forgotten Relics event: earn Merits from XP and by extracting with relics found in lockers, drawers and crates. Rewards include the Saltwalker Outfit.
  • Converging Paths Project (Jun 16 to Jul 27) fills a Display Case; finishing grants a Red-Black Saltwalker, a Sextant charm and Raider Tokens.
  • Free loadouts disabled for Night Raid and Close Scrutiny as a three-week test.
  • Rocketeer now drops Launcher Ammo instead of Heavy Ammo; Reaver Set Bundle added.
  • Denuvo Anti-Cheat expands, with inbox messages about action taken on reports.
