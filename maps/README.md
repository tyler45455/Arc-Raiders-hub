# Map images

Drop one image per map in this folder, named exactly:

- dam-battlegrounds.jpg
- buried-city.jpg
- spaceport.jpg
- the-blue-gate.jpg
- riven-tides.jpg
- stella-montis.jpg
- pendola-pass.jpg
- practice-range.jpg

Use images you have the right to use, and keep each under 1 MB. Maps without an image simply show no picture.

Each map can also have an optional `<name>-detail.jpg` (e.g. `pendola-pass-detail.jpg`). The detail image is what opens when someone enlarges the map; the plain image stays as the default in the Maps tab.
