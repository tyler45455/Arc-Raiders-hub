ARC Tracker sync

This site can only read what ARC Tracker already has, it cannot make ARC Tracker pull new data from the game. Run a sync in the ARC Tracker Link app first, then press Resync here.

Copies your completed quests, stash, workshop levels, learned blueprints, project stages and raid history from ARC Tracker. ARC Tracker gets them from your game account with its Link app. Skill trees are not in ARC Tracker's API, so set those on the Skills page. This site only reads them from ARC Tracker and never touches the game.

In ARC Tracker, open Settings, then Developer Access, and create a key with every permission ticked (Profile, Quests, Stash, Hideout, Projects, Rounds and Blueprints). Paste it here. A key with fewer permissions still works; the parts it cannot read are skipped. After the first sync, the site syncs by itself each time you open it. The key stays in this browser and is only sent to arctracker.io.

Home

    
Your next raid, the closest workshop upgrade, goals and raid stats at a glance. Tap any card's button to see more.

    

    

    
Quest route planner
      
Groups your active quests into raids, busiest map first, so you finish several per trip. Quests that work on any map fill the spare room. Tick a quest when it is done and the plan updates.

      

        

      

      

    

    
Weekly goals
      
Set a target for the next 7 days. Progress counts what you add to the tracker from now on.

      

        

        

      

      

      

    

    
Workshop planner
      
Tick how many levels of each station you have finished. Pick how far to plan ahead: those levels count as needs on the Stash tab (untick “Include” to leave a station out), and the upgrade path below lists them in order with everything they need and where to find it.

      

    

    
    
    
Customize Home
      
Untick a card to hide it, and use the arrows to move it up or down. New-update and starred-condition alerts always show at the top.

      

      

    

    

      Back up or move your data
      
Reset everything to default (the red button below) clears quests, tracker, goals, projects, checklists, notes, pins, loadouts and every other saved setting back to zero. It keeps your language, theme and contrast choices. Export a backup first if you might want it back.

      
Your tracker, goals, starred items, projects and checklist are saved only in this browser. Press Download file to save a backup, then use Import from file on another device. You can also press Export to get the same backup as text and paste it here.

Raid log
      
Log each raid in a few taps to see your extract rate, average haul and profit on every map. Add what your kit was worth (or pick a saved loadout) and profit is the haul minus the kit; a death counts as losing the kit. Saved in this browser and included in backups.
